# Credentials & Portfolio

Portfolio section for academic credentials, professional experience, and technical proficiencies.

**Live URL:** https://porebo.github.io/2026Spring/credentials/

**Coursework hub:** https://porebo.github.io/2026Spring/

This folder is kept separate from the coursework hub root so credential content can be maintained independently, while still publishing through the same GitHub Pages site.
